# GIDANABINCI.COM

A simple responsive restaurant website with:
- GIDANABINCI.COM branding
- Menu: Kunu Aya ($400), Tuwon Shinkafa ($300), Rice ($300), Spaghetti ($340)
- Shopping cart
- Customer order form
- Mobile-friendly responsive design

## Domain
The requested domain is **GIDANABINCI.COM**. A domain name must be registered separately with a domain registrar.

## Publish
Upload `index.html`, `styles.css`, and `script.js` to your web host's public folder. Then connect the GIDANABINCI.COM domain to that hosting provider.

## Currency
Prices are displayed exactly as provided: $400, $300, $300 and $340.
